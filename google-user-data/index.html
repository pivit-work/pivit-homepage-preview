Google 사용자 데이터 이용 안내

게시일 2026년 11월 9일

이 안내는 개인정보처리방침을 보충하여, PIVIT.WORK(이하 "서비스")가 Google API 로 받은 사용자 데이터를 어떻게 쓰는지 알립니다.

제한적 사용 요건 준수

서비스가 Google Workspace API 에서 받은 원본 데이터와 그로부터 만든 데이터의 이용은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

The use of raw or derived user data received from Workspace APIs will adhere to the Google User Data Policy, including the Limited Use requirements.

서비스가 Google API 에서 받은 정보를 쓰고 다른 앱으로 넘기는 일은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

PIVIT.WORK's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

받는 데이터와 쓰는 곳

Google 서비스받는 데이터쓰는 곳
Google 로그인이메일, 이름, Google 계정 식별자로그인과 계정 식별
Google Calendar이용자 캘린더의 일정(제목·설명·시간·참석자·회의 링크)1on1·회의 준비, 회의록과 일정 연결, 이용자가 서비스에서 만든 회의·일정을 이용자의 캘린더에 등록
Google Meet끝난 회의의 녹취(발언자·시각·발언 내용)와 참석자 이름그 회의의 회의록·요약 만들기
Google Drive이용자가 선택 창에서 직접 고른 문서 한 건의 내용그 문서로 회의록 만들기. 고르지 않은 파일은 열 수 없습니다

쓰지 않는 곳

  • Google 사용자 데이터는 위 기능을 제공하거나 이용자에게 보이는 방식으로 개선하는 데만 씁니다.
  • 범용·기반 AI·머신러닝 모델을 만들거나 학습·개선하는 데 쓰거나 넘기거나 팔지 않습니다. 원본 데이터, 모은 데이터, 만들어 낸 데이터 모두 같습니다.
  • 광고(맞춤 광고·재타기팅 포함)에 쓰지 않고, 데이터 브로커 등 제3자에게 팔지 않습니다.
  • 개인정보처리방침 제5조의 처리 위탁(서버 운영, 요청받은 AI 요약 생성) 말고는 다른 곳에 넘기지 않습니다.
  • 사람이 데이터를 읽는 것은 이용자가 특정 데이터를 보는 데 명시적으로 동의한 경우, 보안 목적(버그·악용 조사)에 필요한 경우, 법령을 지키는 데 필요한 경우, 모아서 익명 처리한 데이터를 내부 운영에 쓰는 경우로 한정합니다.

Google user data is used only to provide or improve user-facing features of the service. We do not use, transfer, or sell Google user data, whether raw, aggregated, or derived, to develop, improve, or train generalized or foundational AI/ML models.

  • We do not use Google user data for advertising, including personalized ads or retargeting, and we do not sell it to third parties such as data brokers.
  • We do not transfer Google user data to others except to the service providers listed in Article 5 of our Privacy Policy (server hosting and AI summaries requested by the user).
  • Humans read Google user data only with the user's explicit consent to view specific data, when necessary for security purposes (such as investigating bugs or abuse), to comply with applicable law, or for internal operations using aggregated and anonymized data.

연결 해제와 삭제

이용자는 서비스의 「내 설정 › 개인 연동」에서 Google 연결을 끊을 수 있고, Google 계정의 서드 파티 액세스 화면에서도 권한을 거둘 수 있습니다. 보유 기간과 삭제 요청은 개인정보처리방침을 따릅니다.
